The credential, login payload, session token, and decrypted response bodies were not recorded. Findings combine public login-page calls, static frontend assets, normal read-only page navigation, and an allowlisted subset of non-unique status metadata.

## Capture procedure

- [ ] Preserve the router's current state; do not factory-reset it.
- [ ] Record the software/runtime fields above.
- [ ] Open browser developer tools and select Network.
- [ ] Enable Preserve log; disable cache if needed.
- [ ] Navigate through each visible page without changing settings.
- [ ] Record pages in `ui-pages.md` and requests in `endpoints.md`.
- [ ] Save the raw HAR only under `raw/` and do not commit it.
- [ ] Export configuration if the stock UI offers it; preserve the original privately and record its hash only after checking metadata for identifiers.

## Observations

### Confirmed

- The login page exposes read-only status through `webServer` action 6.
- The frontend feature list reports USSD and ISP update support.
- The feature list disables WPS, 5 GHz operation, WISP, configuration backup/restore, SD-card support, and NAT-forwarding pages for this model configuration.
- Cloud firmware update support is enabled.
- The normal software-update page reports no newer firmware (`hasNewVersion=0`) and did not return a download URL or release note.
- Software reports hardware `M7000(EU) v3.2`, firmware `3.0.2 Build 241129 Rel.3n`, and product region `EU`.
- The authenticated Device Information view is implemented to read `model`, `firmwareVer`, `hardwareVer`, `imei`, `mac`, `imsi`, and `simNumber` from the shared `status` model.
- Raw UI traffic uses token-authenticated CGI calls; GDPR mode adds frontend RSA/AES handling.
- Normal read-only navigation invoked `status`, `wan`, `simLock`, `message`, `voice`, `wlan`, `macFilters`, `connectedDevices`, `lan`, `flowstat`, `power_save`, `update`, `time`, and `log` modules.
- The System Log page exposes log-type and log-level selectors plus a `Debug Log` control. Its behavior has not been activated or characterized.

### Hypotheses and follow-ups

- The presence of identity fields in the shared status model supports, but does not prove, the hypothesis that the TP-Link layer queries modem-owned state.
- Determine whether the `Debug Log` option exports additional diagnostic material without enabling persistent logging or changing configuration.
- Inspect frontend model/action definitions offline before invoking any call not already generated by normal page navigation.
